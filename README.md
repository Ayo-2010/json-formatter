# JSON Formatter

A JSON formatter and validator with pretty printing, minifying and a collapsible tree view.

## Features

- Pretty print with a 2 space, 4 space or minified indent setting
- Collapsible tree view where objects and arrays can be folded and unfolded
- Validation errors reported with the line, column and character position
- Success status showing the total node count of the parsed document
- Syntax colouring for keys, strings, numbers, booleans and null
- Input and output sizes shown in bytes
- Format, Minify, Sample, Copy output and Clear buttons, plus Ctrl/Cmd + Enter

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
